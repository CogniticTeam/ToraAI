# Tora v1.1.0

本次更新带来系统字体选择、多语言对话命名，以及模型菜单、设置和背景显示的一系列改进。

## 新增与改进

- **系统字体：**在“设置 → 主题”末尾选择电脑已安装的字体，支持搜索、预览、重新读取和恢复默认；选择会保留到下次启动。优化 macOS 字体扫描速度。
- **多语言命名：**新对话会根据当前界面语言，用 AI 简短总结第一条消息作为名称，改善总是生成中文标题的问题。命名在后台完成，并保留手动修改的名称。
- **模型菜单：**改善 ToChat 官方模型菜单在长对话中打开时的响应，保留原有模型与思考强度选择方式。
- **数据管理：**聊天记录导入入口移至“设置 → 数据管理”，继续支持从本机 Codex 和 Claude Code 导入。
- **设置一致性：**统一标题、说明间距、开关和字体控件尺寸，补充键盘焦点提示与表单名称；移除“开发者&调试”设置页。

## 修复

- 修复设置下拉菜单在窗口底部被裁切的问题，支持边界避让、滚动和键盘选择。
- 修复默认音量为 60% 时选择框显示“请选择”的问题，准确显示已有音量设置。
- 改进设置窗口的焦点隔离、Esc 关闭及关闭后的焦点返回；打开导入等新弹窗时不再抢占焦点。
- 恢复原有深灰主题，并修复自定义背景在深色模式下不显示的问题。
- 将共享弹窗及侧栏关闭按钮的辅助描述改为当前界面语言。
- 官网同步修正设置和额度入口图标，并改善手机侧栏与弹窗的交互。

## English

Tora v1.1.0 adds system-font selection and localised conversation titles, with improvements to model menus, settings and custom backgrounds.

- Select installed system fonts at the end of Settings → Theme, with search, preview, refresh and persistent preferences. Speed up font enumeration on macOS.
- Generate concise first-message titles in the selected interface language. Keep title generation in the background and preserve manual names.
- Improve responsiveness when opening the official ToChat model menu in long conversations, retaining the existing model and reasoning-effort controls.
- Move Codex and Claude Code conversation import to Settings → Data Management.
- Align settings headings, spacing, switches and font controls; add keyboard-focus indicators and accessible labels. Remove the Developer & Debug settings page.
- Prevent settings menus from being clipped at window edges and support scrolling and keyboard selection.
- Show the actual saved sound volume, including the 60% default.
- Improve settings focus containment, Escape dismissal and focus restoration without stealing focus from a newly opened dialog.
- Restore the original dark-grey theme and fix custom-background visibility in dark mode.
- Localise shared dialog and sheet close-button labels.
- Update website settings/quota icons and improve mobile sidebar-to-dialog transitions.

macOS: Developer ID signed and Apple notarised universal DMG/ZIP, macOS 13+. Windows: unsigned x64 installer; Bash requires Git for Windows. Updater manifests, blockmaps and SHA256 checksums are included.

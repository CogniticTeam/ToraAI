# Tora v1.0.7

新增四款内置模型，并改进对话命名、模型菜单与额度管理。

## 新增功能

- ToChat 与 ToCode 新增 **Claude Opus 5、GPT-6 Astra、GPT-6 Sol、GPT-6 Luna**，保留 DeepSeek Flash、Gemini 3.8 Flash、GPT-6.1 Sol 与自定义模型。
- 内置模型默认使用各自最大上下文窗口，移除手动上下文选择入口。GPT 系列为 1.05M、Claude 为 1M；为系统提示和输出预留空间。
- 新对话使用 AI 简短概括首条消息，后台更新标题与侧栏。只命名一次，不覆盖手动名称；超时或失败保留占位名。
- 新增“设置 → 额度”，查看套餐、滚动窗口及有效期30天的重置卡，支持手动使用重置卡。
- 管理端支持对单个、多个或所有用户重置额度、发放重置卡及手动开通订阅。保留历史用量与审计记录，运行中的官方任务不会被重置打断。

## 界面改进与修复

- 模型选择恢复原来的列表与详情面板，思考强度使用原菜单选项。
- 修复思考强度菜单靠近窗口底部时显示不完整的问题，自动避让窗口边缘，小窗口支持滚动。
- 对话首条消息发出后立即隐藏“聊天 / 工作”切换，已有对话不再显示；空白新对话可选择模式。
- 移除 ToCode 输入框上方重复的额度进度条，额度信息集中在账户菜单与设置中查看。
- 额度设置页的字号、卡片和间距对齐其他设置页，使用独立的仪表图标。
- 优化新版下载进度条，使用简洁的细进度条和独立百分比显示。
- 优化订阅界面，Pro 为推荐套餐；额度耗尽提示显示在输入框内。
- 修复新 GPT 模型的思考档位转发和多轮推理上下文保留，命名请求不会占用 Agent 正文并发槽位。

## 下载

- **macOS：**`Tora-1.0.7-mac.dmg`，支持 macOS 13+，Apple 芯片与 Intel 通用版本，Developer ID 签名并经 Apple 公证。
- **Windows：**`Tora-1.0.7-win-x64.exe`，Windows x64。安装包未签名；Bash 工具需要 Git for Windows。
- 提供 macOS ZIP、自动更新文件、blockmap 与 SHA256 校验文件。

普通 ToChat 聊天不占用工作额度；ToChat 工作模式和 ToCode 共用订阅滚动额度。本版未开放附加额度购买。

## English

Tora v1.0.7 adds four built-in models and improves conversation naming, model menus and quota management.

- Add Claude Opus 5, GPT-6 Astra, GPT-6 Sol and GPT-6 Luna to ToChat and ToCode.
- Use each built-in model's maximum context by default, with space reserved for instructions and output; remove the context selector.
- Generate a short AI title from the first message without delaying the reply. Preserve manual names and deleted conversations.
- Add quota settings, 30-day reset cards and administrative controls for quota resets, card grants and subscriptions.
- Restore the original model and thinking menus. Keep thinking options inside window boundaries and make small menus scrollable.
- Hide the Chat/Work switch immediately after a conversation starts. Keep it available in fresh drafts.
- Remove the duplicate quota bar above the ToCode composer, align quota settings with other settings pages, and give quotas a distinct icon.
- Refine download progress, recommend Pro in the subscription screen, and show quota exhaustion notices inside the composer.
- Preserve reasoning effort and multi-turn reasoning context for the newly added GPT models.

macOS: Developer ID signed and Apple notarised universal DMG/ZIP, macOS 13+. Windows: unsigned x64 installer; Bash requires Git for Windows. Updater manifests, blockmaps and SHA256 checksums are included.

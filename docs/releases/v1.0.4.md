# Tora v1.0.4

本次更新完善多语言体验、权限控制和软件更新说明。

## 本次更新

- 对话进行中可以调整权限模式，新设置会作用于后续工具操作；仍需确认的操作继续等待授权。
- 修复“聊天 / 工作”和 ToCode / ToChat 切换时欢迎标题偶尔重叠的问题。ToCode 欢迎语改为“Tora要构建些什么？”。
- 补齐各语言的欢迎标题和模式相关文案，避免切换语言后回退为英文。
- English 分为 UK、US，繁体中文分为中国香港、中国台湾；语言选择加入国家或地区旗帜，保留旧语言设置的兼容。
- 修复语言选择窗口关闭按钮无法点击的问题。
- 更新页面显示对应版本的 GitHub Release 发行说明；升级后首次打开展示一次，也可在“关于”页随时查看，已获取的说明可离线读取。

## 下载与更新

- **macOS：**`Tora-1.0.4-mac.dmg`，支持 macOS 13+、Apple 芯片与 Intel 芯片，使用 Developer ID 签名并经 Apple 公证。
- **Windows：**`Tora-1.0.4-win-x64.exe`，支持 Windows x64。安装包未签名，可能出现“未知发布者”或 SmartScreen 提示。
- 同时提供 macOS ZIP、两平台自动更新文件、blockmap 和 SHA256 校验文件。
- Windows 的 Bash 工具需要 Git for Windows；不支持进程沙箱时会明确拒绝执行。

## English

Tora v1.0.4 improves localisation, permission controls and release-note visibility.

### What's new

- Change permission modes during a conversation. The new mode applies to subsequent tool actions, while operations that require approval continue to wait for confirmation.
- Fix overlapping welcome headings when switching between Chat / Work and ToCode / ToChat. The ToCode greeting is now “What should Tora build?”.
- Localise welcome headings and mode controls across supported languages.
- Separate UK / US English and Hong Kong / Taiwan Traditional Chinese options, add country or region flags, and preserve legacy language preferences.
- Fix the language selector's close button on desktop.
- Show the matching GitHub Release notes during updates and once after upgrading. View them again from About; cached notes remain available offline.

### Downloads and updates

- **macOS:** `Tora-1.0.4-mac.dmg` supports macOS 13+ on Apple silicon and Intel Macs, with Developer ID signing and Apple notarisation.
- **Windows:** `Tora-1.0.4-win-x64.exe` supports Windows x64. It is unsigned and may show an Unknown Publisher or SmartScreen prompt.
- Includes the macOS ZIP, updater manifests for both platforms, blockmaps and SHA256 checksums.
- The Windows Bash tool requires Git for Windows. Unsupported process sandboxing explicitly refuses execution.

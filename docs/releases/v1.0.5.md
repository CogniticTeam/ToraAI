# Tora v1.0.5

本次更新为 ToChat 带来更多内置模型，并加入枢流云模型提供商。

## 本次更新

- ToChat 新增 **Gemini 3.8 Flash** 和 **GPT-6.1 Sol** 内置模型，保留 DeepSeek Flash；可在对话空闲时切换，已有对话保留原模型。
- Gemini 3.8 Flash 提供低、中、高三个思考档位；GPT-6.1 Sol 提供低、中、高、极高、最大五档。所选档位会按对应参数发送，“中”档不会被当作“高”档。
- GPT-6.1 Sol 支持流式回复及工具调用，可用于联网搜索和工作任务。
- 模型设置新增 **枢流云**，支持使用自己的 API Key 获取模型列表并接入 OpenAI 兼容接口。
- Google Gemini 的模型与提供商入口统一使用 Gemini 星形图标。
- 官网 ToChat 对话记录保存所选模型与思考档位；各语言补齐新增档位文案。

## 使用说明

- 内置模型通过 Tora 服务端调用，用户无需填写个人模型 API Key，聊天与工作额度沿用原规则。自定义模型按所接入提供商的账户与计费规则使用。
- GPT 内置模型所用枢流云令牌当前为 **default 分组**，不承诺采用 `codex 0.07` 价位；最终上游价格以提供商实际配置及结算为准。
- 模型配置及个人 API Key 会同步到当前 Tora 账户。内置模型的服务端密钥不包含在安装包或公开源码中。

## 下载与更新

- **macOS：**`Tora-1.0.5-mac.dmg`，支持 macOS 13+、Apple 芯片和 Intel 芯片，使用 Developer ID 签名并经 Apple 公证。
- **Windows：**`Tora-1.0.5-win-x64.exe`，支持 Windows x64。安装包未签名，可能出现“未知发布者”或 SmartScreen 提示。
- 同时提供 macOS ZIP、两平台自动更新元数据、blockmap 和 SHA256 校验文件。
- Windows 的 Bash 工具需要 Git for Windows。

## English

Tora v1.0.5 adds more built-in ToChat models and the Shuliuyun provider.

### What's new

- Add **Gemini 3.8 Flash** and **GPT-6.1 Sol** as built-in ToChat models, alongside DeepSeek Flash. Switch models while idle; existing conversations keep their original selection.
- Gemini offers low, medium and high reasoning effort. GPT-6.1 Sol offers low, medium, high, extra high and max. Medium is preserved instead of being read as high.
- GPT-6.1 Sol supports streaming replies and tool calling for web search and work tasks.
- Add the **Shuliuyun** provider to model settings, with model discovery and OpenAI-compatible API access using your own API key.
- Use the Gemini star icon across Gemini model and provider entries.
- Save the selected model and reasoning effort with conversations on the ToChat website, and localise the new effort labels.

### Usage and billing

- Built-in models use Tora's server-side credentials and the existing ToChat quotas. Custom models follow your provider account's billing rules.
- The upstream token used for built-in GPT currently belongs to the **default group**. The `codex 0.07` price tier is not promised; actual provider settings and settlement determine upstream costs.
- Personal model configuration and API keys sync to your Tora account. Built-in server credentials are not included in installers or public source.

### Downloads and updates

- **macOS:** `Tora-1.0.5-mac.dmg` supports macOS 13+ on Apple silicon and Intel Macs, with Developer ID signing and Apple notarisation.
- **Windows:** `Tora-1.0.5-win-x64.exe` supports Windows x64. It is unsigned and may show an Unknown Publisher or SmartScreen prompt.
- Includes the macOS ZIP, updater manifests, blockmaps and SHA256 checksums. Windows Bash requires Git for Windows.

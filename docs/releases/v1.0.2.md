# Tora v1.0.2

Tora v1.0.2 正式发布，首次提供 Windows x64 安装包，继续提供 macOS 通用安装包。

## 本次更新

- 品牌统一为 Tora，并保留旧版本账户、本地数据与更新入口的兼容迁移。
- 桌面端和官网支持 14 种语言，新增语言选择、系统语言检测和阿拉伯语 RTL 布局；消息翻译跟随界面语言。
- 新增毛玻璃启动页、可配置的主题背景与界面动画，改善首次使用引导。
- 优化消息气泡发送动画、复制按钮、自动滚动、任务过程折叠及输入框布局。
- 改善消息管理、赞助名单、系统通知、浏览器、终端及变更预览体验。
- 调整打包文件白名单，仅保留运行所需代码与资源，不再重复携带前端开发文件、测试或本地凭据。

## 下载与更新

- macOS：`Tora-1.0.2-mac.dmg`，支持 macOS 13+、Apple 芯片和 Intel 芯片；经 Developer ID 签名及 Apple 公证。
- Windows：`Tora-1.0.2-win-x64.exe`，首次 Windows x64 安装版。此版本**未签名**，安装时可能出现“未知发布者”或 SmartScreen 提示；请只从本仓库发行版或官网下载安装包并核对校验值。
- 发布同时提供 macOS ZIP、两平台更新元数据和 blockmap，用于已安装应用的更新检测、后台下载与重启安装。

## Windows 首发注意事项

- Bash 命令工具需要安装 Git for Windows（含 Bash），内置终端使用系统 cmd.exe。
- Windows 暂不提供系统级 Bash 进程沙箱。默认沙箱启用时会明确拒绝命令，不会悄悄降级；如需执行命令，可在确认风险后于设置中关闭进程沙箱并保留手动审批，或显式选择完全访问模式。
- 首发验证覆盖 Windows 构建环境中的安装、应用启动、内置前端和命令工作目录；不代表所有 Windows 设备与第三方模型服务均已验证。

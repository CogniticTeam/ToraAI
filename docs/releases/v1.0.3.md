# Tora v1.0.3

本次更新改善聊天与任务导航，新增桌面聊天记录导入，并同步优化官网 ToChat。

## 本次更新

- 桌面版支持从本机 Codex 和 Claude Code 导入聊天记录：扫描或选择 JSON/JSONL 文件，先预览再导入，保留正文和时间，避免重复导入。
- 同一轮工具调用汇总显示，去除工具列表与结果卡片边框，保留逐条展开、运行状态和结果。
- 修复点击“新任务”跳回上次会话的问题；首次发送后自动选中对应会话。
- 放大 ToCode/ToChat 模式入口，缩小展开菜单，账户菜单新增退出登录。
- 改善认证服务暂时不可用时的恢复体验、模型配置同步与消息切换稳定性。
- 官网 ToChat 增加两侧留白、默认显示发送时间，改善手机导航和 iOS 键盘打开时的布局，并补齐多语言文案。

## 下载与更新

- macOS：`Tora-1.0.3-mac.dmg`，支持 macOS 13+、Apple 芯片与 Intel 芯片，使用 Developer ID 签名并经 Apple 公证。
- Windows：`Tora-1.0.3-win-x64.exe`，适用于 Windows x64；安装包未签名，可能出现“未知发布者”或 SmartScreen 提示。
- 同时提供 macOS ZIP、两平台更新元数据、blockmap 和 SHA256 校验文件。
- Windows Bash 工具仍需要 Git for Windows；默认进程沙箱不支持 Windows 时会明确拒绝执行，不会静默降低保护。

官网：https://ohfun.online/
问题反馈：https://github.com/CognitictTeam/ToraAI/issues

## English

Tora v1.0.3 improves chat and task navigation, adds desktop chat-history import, and updates the official ToChat workspace.

### What's new

- Import local Codex and Claude Code conversations on desktop by scanning or selecting JSON/JSONL files. Preview before importing; message text and timestamps are preserved and duplicate imports are avoided.
- Group tool calls within each reply into one expandable summary, remove tool-card borders, and retain individual details and execution states.
- Fix New Task reopening the previous conversation. The first message creates and selects its own conversation.
- Enlarge the ToCode/ToChat mode trigger, make its menu more compact, and add account sign-out.
- Improve recovery from temporary authentication-service failures, model synchronization, and conversation switching.
- Improve the web ToChat layout with horizontal spacing, visible send times, mobile navigation, iOS keyboard handling, and complete multilingual copy.

### Downloads and updates

- **macOS:** `Tora-1.0.3-mac.dmg` supports macOS 13+ on Apple silicon and Intel Macs, with Developer ID signing and Apple notarization.
- **Windows:** `Tora-1.0.3-win-x64.exe` supports Windows x64. It is unsigned and may show an Unknown Publisher or SmartScreen prompt.
- Includes the macOS ZIP, updater manifests for both platforms, blockmaps, and SHA256 checksums.
- The Windows Bash tool still requires Git for Windows. Unsupported process sandboxing explicitly refuses execution instead of silently reducing protection.

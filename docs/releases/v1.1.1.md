# Tora v1.1.1

本次更新重制登录流程，加入通行密钥支持，整合内置浏览器与工具标签页，并改善消息操作、网页预览和模型权限体验。

## 新增与改进

- **登录与通行密钥：**采用居中分步登录界面，支持密码、邮箱验证码、找回密码和通行密钥；账户设置可添加和移除通行密钥。加入入场、步骤切换及等待动画，并适配减少动态效果偏好。
- **统一工具侧栏：**网页、终端、变更、技能等工具在内置浏览器的同一标签栏中打开。关闭最后一个标签页会收起侧栏，保留其它标签页的状态。
- **网页预览：**网页任务完成后提供本地预览卡片，在对话右侧直接打开；支持选择网页元素并附到输入框。
- **消息操作：**新增单条消息显示记录删除与沙化动画；删除按钮位于复制按钮左侧。用户和 AI 消息的时间与操作栏统一在悬停或聚焦时显示，触屏轻触消息显示，生成中的 AI 回复隐藏操作栏。
- **工作记录：**ToCode 与 ToChat 工作模式共用对话记录；普通聊天独立保存。左侧采用统一对话列表。
- **官方模型：**支持动态模型目录、渠道、订阅权限和 Credits 价格更新，完善 Grok、GLM 与 Claude 模型的显示和接入。支持豆包工作模式的免费日限额及订阅 Credits 计费。
- **工具和额度界面：**补充工具名称、输入输出和授权提示翻译；剩余额度使用整数百分比，调整重置卡到期说明，修正 Pro 额度窗口显示。
- **更新与账号：**加入签名前端资源更新、空闲切换及失败回退；补充使用准则入口、临时风控限制与申诉入口。付费权益和申诉规则保持服务端现有政策。

## 修复

- 修复首条消息发送后偶尔不显示、模型目录请求失败后列表丢失的问题。
- 修复桌面模型请求未正确继承系统网络代理的问题。
- 修复非 Git 文件夹的变更预览，以及侧栏内容高度、间距、开关动画和最后标签页关闭行为。
- 修复复制按钮只在气泡正文悬停时出现、移到消息底部就消失的问题。
- 移除模型切换提示和无权限模型旁重复的套餐文字，保留草稿和输入框内容。

消息删除针对显示记录，不撤销已执行的工具操作，也不回滚智能体上下文或检查点。通行密钥验证在支持 WebAuthn 的系统浏览器中完成。

## English

Tora v1.1.1 introduces a redesigned sign-in flow with passkeys, a unified browser/tool sidebar, and improvements to message controls, webpage previews and model access.

- Use password, email-code and passkey sign-in, password recovery, and passkey management. Enjoy step transitions and loading feedback with reduced-motion support.
- Open webpages, terminal, changes and other tools in one built-in browser tab strip. Closing the final tab collapses the sidebar.
- Open locally served webpage previews beside the conversation and attach selected webpage elements to the composer.
- Delete individual displayed messages with a sand animation. Delete sits to the left of Copy; timestamps and actions share hover/focus visibility. Tap messages on touchscreens; in-progress replies hide their actions.
- Share work history between ToCode and ToChat work mode while keeping ordinary chat separate.
- Receive dynamic official-model catalogs, access rules and Credits pricing. Improve Grok, GLM and Claude integration and support Doubao work quotas and subscription usage.
- Localise tool and permission labels, show whole-number quota percentages, and correct Pro quota-window and reset-card expiry displays.
- Add signed renderer updates with idle application and rollback, policy links and account appeal access.
- Fix missing first messages, disappearing model catalogs, system-proxy inheritance, non-Git change previews, sidebar sizing and message-control hover behaviour.

Deleting a displayed message does not undo tools, agent context or checkpoints. Passkeys use a WebAuthn-capable system browser.

macOS: signed and Apple-notarised universal DMG/ZIP, macOS 13+. Windows: unsigned x64 installer; Bash requires Git for Windows. Update manifests, blockmaps, licence and SHA256 checksums are included.

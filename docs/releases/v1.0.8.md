# Tora v1.0.8

新增豆包免费聊天模型，支持多模态理解，并改善聊天输入与输入法体验。

## 新增功能

- 内置 **Doubao Seed 2.1 Lite**（`doubao-seed-2-1-lite-260915`），仅供 **ToChat 聊天模式**使用，无需订阅，不消耗 Agent Credits。
- 支持文字、图片、音频和视频理解，默认使用模型的最大上下文窗口，提供低、中、高三档思考强度。
- 音频支持 WAV、MP3、FLAC、AAC、M4A，单文件最多 10 MB；视频支持 MP4、MOV、AVI，单文件最多 20 MB。
- 模型旁新增“免费”标签，悬停显示：“仅限ToChat聊天模式使用，本模型永久免费，不消耗你的额度”。提示支持全部界面语言，移开鼠标后自动收起。
- 豆包官方模型在 ToChat 工作模式和 ToCode 中自动隐藏，服务端也会拒绝这些模式的调用。其他模型的使用方式保持一致。

## 改进与修复

- ToChat 聊天输入自动折到第二行或手动换行时，切换为文字在上、操作按钮在下的布局；删回一行后恢复胶囊样式。
- 修复网页端输入法按 Enter 确认候选字时误发送消息的问题，保留正常 Enter 发送及 Shift+Enter 换行操作。
- 改进多模态附件传输、多轮对话与联网工具结果续聊。
- 切换豆包与 GPT 时，分别处理各自的加密思考记录，避免不同提供商的上下文混用。

## 下载

- **macOS：**`Tora-1.0.8-mac.dmg`，支持 macOS 13+，Apple 芯片与 Intel 通用版本，Developer ID 签名并经 Apple 公证。
- **Windows：**`Tora-1.0.8-win-x64.exe`，Windows x64。安装包未签名；Bash 工具需要 Git for Windows。
- 同时提供 macOS ZIP、自动更新文件、blockmap 和 SHA256 校验文件。

## English

Tora v1.0.8 adds a free multimodal chat model and improves composing messages with IMEs.

- Add **Doubao Seed 2.1 Lite** to **ToChat chat mode**. No subscription is required and Agent Credits are not consumed.
- Understand text, images, audio and video; use the model's maximum context by default and choose low, medium or high reasoning effort.
- Audio supports WAV, MP3, FLAC, AAC and M4A, up to 10 MB per file. Video supports MP4, MOV and AVI, up to 20 MB per file.
- Add a localised tooltip to the Free label, explaining that the model is permanently free for ToChat chat mode and does not consume the user's quota. The tooltip closes when the pointer leaves the label.
- Hide this official model in ToChat Work and ToCode, with matching service-side restrictions.
- Expand the chat composer into two rows for wrapped text or manual newlines; return to the capsule layout when content fits one line.
- Prevent IME candidate-confirmation Enter from sending messages; retain normal Enter to send and Shift+Enter for a newline.
- Improve multimodal transport, multi-turn conversation and web tool continuation. Keep Doubao and GPT encrypted reasoning contexts separate when switching models.

macOS: Developer ID signed and Apple notarised universal DMG/ZIP, macOS 13+. Windows: unsigned x64 installer; Bash requires Git for Windows. Updater manifests, blockmaps and SHA256 checksums are included.

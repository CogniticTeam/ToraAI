# CoCode Desktop v1.0.1

本次更新主要改善首次使用体验和日常工作界面，并精简了部分功能。

- 新增首次启动引导；聊天输入区、主题背景与设置界面得到调整。主题支持预设图片、无背景和自定义背景。
- 优化内置浏览器与终端的交互；非 Git 文件夹中的「变更预览」现在显示明确提示，不再铺满 Git 帮助文本。
- 移除「项目影响雷达」「可验证交付」和「运行记录」。项目钩子仍可在独立面板中查看和管理。
- 本次提供 macOS 13 及更新系统的通用安装包，包含 Apple 芯片与 Intel 架构。应用和 DMG 均已使用 Developer ID 签名并通过 Apple 公证。
- 随发行版提供 ZIP、blockmap 与 `latest-mac.yml`，供应用内更新使用。Windows 安装包本次暂未提供。

---

This update improves the first-run experience and everyday workspace UI while simplifying the feature set.

- Added first-run guidance and refined the chat composer, themes, and settings. Themes now support presets, no background, and a custom background.
- Improved the built-in browser and terminal. Change Preview now shows a concise message for folders that are not Git repositories.
- Removed Project Impact Radar, Verifiable Delivery, and Run History. Project hooks remain available in their own panel.
- The macOS 13+ universal build supports both Apple silicon and Intel. The app and DMG are Developer ID signed and Apple-notarized.
- ZIP, blockmaps, and `latest-mac.yml` are included for in-app updates. A Windows installer is not included in this release.

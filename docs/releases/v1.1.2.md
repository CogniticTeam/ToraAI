# Tora Desktop v1.1.2

- 工作会话改为按需发现工具，并改进上下文压缩、会话恢复和长工具输出的处理。
- 支持在桌面设置中管理 MCP 服务、技能和插件，也可接入自己的 Codex 订阅。
- 权限菜单提供请求批准、帮我批准和完全访问权限三种模式。
- 调整模型与推理强度选择、消息显示和区域服务启动流程。
- 移除 Folia 音乐功能。

macOS 通用安装包支持 macOS 13 及以上版本，适用于 Apple 芯片和 Intel 芯片。Windows 提供未签名的 x64 安装包，使用 Bash 工具需安装 Git for Windows。发行附件包含 SHA-256 校验文件和自动更新元数据。

[官网下载](https://toraai.cogniticteam.com/?lang=zh#download)

## English

- Work sessions now discover tools on demand and improve context compaction, session recovery, and handling of long tool output.
- Manage MCP servers, skills, and plugins in desktop settings, and connect your own Codex subscription.
- Choose from three permission modes in the permission menu.
- Updated model and reasoning controls, message rendering, and regional service startup.
- Folia music has been removed.

The universal macOS installer supports macOS 13 or later on Apple silicon and Intel. The Windows x64 installer is unsigned. Bash tools require Git for Windows. Release assets include SHA-256 checksums and update metadata.

# GLM 5.3 官方模型

通过枢流云 `https://shuliuyun.com/v1/chat/completions` 接入 `glm-5.3`，密钥只放在 Worker Secret `SHULIUYUN_GLM_API_KEY` 中。ToChat 普通聊天不消耗 Agent 额度，工作模式与 ToCode 使用共享订阅池。

依据 [Z.ai GLM 5.3 文档](https://docs.z.ai/guides/llm/glm-5.3)，该模型仅支持文字，始终启用思考，提供 `low`、`high`、`max` 三档。发送 `thinking.type=enabled` 及顶层 `reasoning_effort`，保留工具调用和助手思考记录用于续接。桌面运行配置、模型卡、网站附件与 Worker 验证均限制为纯文本，避免通用视觉推断错误。

保持原有模型选择框，不增加上下文选择器。官方称上下文为 1M，本实现按 1,000,000 配置，运行预算另预留输出与系统空间。单次输出继续受服务端现有 16,384 上限与可用额度限制。

## Credits

沿用供应商成本 × 400 Credits/CNY 的服务费率，价格来自用户提供的枢流云截图。

| 类型 | 价格 / 1M tokens | Credits / 1M tokens |
| --- | ---: | ---: |
| 输入 | ¥1.2 | 480 |
| 缓存输入 | ¥0.12 | 48 |
| 输出（含思考） | ¥4.8 | 1920 |

每次按实际输入、缓存输入、输出分别结算。缓存从输入中扣除，不重复计费；思考已包含在输出中，不额外扣费。截图未声明长上下文加价；供应商费率变化可通过 `AGENT_CREDIT_RATES` 覆盖。

## 供应商验证

设置 Secret 前验证同一把密钥的流式文本、工具调用与结果续接。令牌须允许 `glm-5.3`，并选择具有可用渠道的分组。未配置 Secret 时，模型保持不可用，不隐式回退其他模型。模型原厂能力与枢流云调用验证分别记录。2026-10-10 实测低档流式回复、高档函数调用、极致档工具结果续接均返回 HTTP 200；响应模型名为 `glm-5.3`，流式用量含缓存输入，极致档返回思考内容。未用百万 tokens 请求实测上下文上限。

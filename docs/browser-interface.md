# 内置浏览器界面

浏览器使用同一套标签栏、地址栏和新标签页，可在全屏入口和对话右侧栏之间切换。标签页及页面由常驻宿主管理，切换视图不销毁网页；只有关闭标签页才销毁对应页面。

新标签页提供当前上下文可用的工具：ToCode 的变更和终端、工作对话的侧边聊天、新标签页及设置。没有对应工作上下文时不展示不可用工具。推荐区域使用其他已打开标签及官方链接，去重并限制为四个，不新增持久浏览历史或向外部服务查询图标。

全屏入口保存来源对话路径。返回侧边聊天时恢复该对话并打开浏览器侧栏；请求其他工具时，短期请求只由匹配的对话接收，并只消费一次。地址栏仍使用已配置的搜索引擎，支持网址及关键词输入，输入法确认不会触发导航。

窄侧栏中地址栏移到第二行，工具变为单列，推荐变为两列。颜色与字体沿用应用主题；支持深色模式、键盘标签切换、可见焦点以及减少动画偏好。更多菜单保留在系统浏览器打开、元素选择及设置操作。

验证：浏览器路由/推荐/工具请求测试、前端回归及导航安全检查；桌面原生 WebView 复核网页导航、弹出标签、输入状态保留及全屏/右侧栏切换；360px 布局与深色样式使用真实共享组件检查。网页兜底环境使用 iframe，受网站嵌入限制约束。源代码及开发版验证与已发布安装版应分别确认。

右侧栏直接挂载内置浏览器，不经过通用 Panel 的标题、背景、阴影或内边距。关闭侧栏按钮位于浏览器标签栏，与标签页和扩大按钮同属一层。其他侧栏面板保留原有布局。

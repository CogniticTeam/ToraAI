# 桌面端多语言

界面语言集中在 `packages/desktop/frontend/src/i18n/languages.ts`：简体中文、繁体中文、英语，以及日语、韩语、法语、德语、意大利语、阿拉伯语、西班牙语、葡萄牙语、俄语、印地语和文言文（`lzh`）。系统区域设置按语言主标签归一，如 `ja-JP`、`pt-BR` 和 `ar-SA`；`zh-TW` 归为繁体中文。用户手动选择保存在 `tora_language_preference`，优先于系统语言。

新增语言的词库按需加载；初始语言在 React 挂载前装入。阿拉伯语把文档方向设为 RTL，其他语言使用 LTR。Language 弹窗和设置页共用同一语言列表。桌面原生菜单、更新提示及新消息通知使用 `packages/desktop/native-locales.json`。

词库源是 `en.json`；文言文以 `zh.json` 为源。`node scripts/generate-locales.mjs <code>` 可生成或更新一个语言，`--native-only` 只更新原生词条。脚本通过现有 Tora 模型配置调用翻译模型，将分片缓存到被 Git 忽略的 `output/i18n-translation-cache/`；词条数、插值占位符、HTML 标签、行内代码和产品名均会核对，失败时不会写出不完整的词库。改动源文案后缓存按源内容哈希失效。

验证：`npm test` 检查所有词库和原生文案；`npm run test:ui:critical` 逐一加载新增语言的登录页，检查阿拉伯语方向、搜索和运行时切换；`npm run test:bundle` 检查首包没有引入未使用的语言包。

这些译文是机器生成后经过结构校验的初稿。首次同意、隐私和跨境传输等法律文案在正式对外发布前仍需母语与法律审校。当前部分原先直接写在专家面板中的中英双语句子未进入 i18next，新语言会显示其英文版本。

## 猫娘彩蛋

仅中文（含繁体、文言文）与日语界面的聊天输入框识别完整暗号：中文为 `喵喵喵` / `猫娘语`，日语为 `にゃにゃにゃ` / `猫娘語`。输入法结束组字后提示添加，取消保留草稿。添加成功同时解锁 `zh-Neko`（猫娘语（中文））与 `ja-Neko`（猫娘語（日本語）），自动切换到对应版本并清空暗号。解锁前，两种语言不会出现在语言列表中。

语言包解锁和人格开关通过本地 `/admin/catgirl` 保存到 Tora 配置；浏览器缓存解锁状态以恢复界面语言。「设置 → 智能体 → 猫娘人格」默认关闭，开启后从下一轮对话生效，包括 ToCode、自定义智能体与 ToChat。引擎在系统提示词末尾重新注入应用人格，关闭后刷新系统消息并移除旧注入。人格只影响自然语言语气；实际口吻遵循程度取决于接入模型。

添加后，左下角账户菜单显示「停用猫娘语言包」（日语及英语界面使用对应文案）。停用会同时关闭人格、隐藏两套猫娘语言和人格开关，并恢复添加前的准确界面语言，包括繁体中文。旧版已添加但未记录原语言时，恢复对应的普通中文/日语。停用状态会持久保存，随后可再次输入暗号添加；停用请求失败时保留现状并提示重试。

`node scripts/generate-catgirl-locales.mjs` 从现有中日词库生成完整猫娘词库及原生菜单文案，常用交互单独润色；插值、标签、代码、语言名称、法律文案与机器使用的提示保留原文。先执行 `npm run build --prefix packages/desktop/frontend`，再执行 `npm run test:catgirl`，验证词库、后端请求注入及真实浏览器交互。测试使用临时 TORA_HOME、模拟模型与认证数据，不修改用户配置；截图在 `output/catgirl-qa/`。

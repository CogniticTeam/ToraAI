# 消息沙化删除

ToCode、桌面 ToChat 和网页 ToChat 的消息菜单提供单条删除。长按 550ms、右键，或聚焦“消息操作”按钮打开菜单；滚动、指针离开和移动超过 8px 会取消长按。回复进行中暂停删除。

保存成功后才开始视觉删除。气泡的像素在本机通过 html-to-image 转成透明画布，采样约 1500 粒沙；颜色来自采样点 RGBA。风从气泡自身左缘向右扫过 800ms，每粒向右上漂移、轻微抖动、缩小淡出 1000ms。原内容同步裁切，不整条淡出。最后收起消息高度及相邻 24px 间距，下面内容在 300ms 内补位。

沙粒只使用一个 Canvas。截图和覆盖层均限制像素预算；截图失败或超时保留逐步擦除回退。减少动态效果偏好或应用动画关闭时直接删除。切换页面取消动画、释放画布和计时器；保存失败保留消息并显示错误。

桌面端用消息删除日志及 ID 墓碑保存，恢复事件日志不会复活已删气泡。网页版用 IndexedDB 事务更新当前账号的单条消息，保留标题等其它字段，发送流程不会重新保存正在删除的消息。此操作删除显示记录，不撤销已执行的工具操作，也不回滚智能体上下文、检查点或压缩摘要。

验证使用可丢弃的本地示例，不读取或删除真实用户消息。
